### Step 5: Item 2.3 — Leaky-Integrate Inhibition

Implement a second layer type next to `AutapticLayer`, with no unroll steps (one forward pass per input).
The inhibition at each input is a weighted sum of the signals of the preceding inputs in the stream, with weights decaying over time, as in leaky-integrate-and-fire neurons.
The researcher chose "across consecutive samples in the stream" as the meaning of "past inputs".

Proposed implementation (agent decision, unconfirmed; flag it in the lab book):

1. Per neuron, the inhibition for sample `i` is `Σ_{k≥1} λ^(k-1) · y_{i-k}` (or the equivalent normalised form), computed with a lower-triangular decay matrix along the batch dimension.
   This avoids a Python loop over samples.
2. The state is carried over, detached, between consecutive batches.
   It is reset at each stage boundary and at the start of each evaluation pass.
3. Combine with the output exactly as the gate variant does: `y * (1 - weight · inhibition)`.
   Keep the activation-scheme handling (`tanh(y/2)` for `relu_sigmoid`) consistent with `AutapticLayer`.
4. The decay `λ` is a parameter.
   Run one primary value, and at most two more if time permits.
   Justify the primary value in the lab book.
5. Consequence to document: with shuffled training batches, neighbouring samples are random classes, so the integrated signal acts like a running population-level activity estimate.
   Evaluation results also depend on test-set order and batch size.
   State this limitation, and fix the test order and batch size.
6. Add the layer to `models.py`, `run_config.py` and `sweep.py` through new, defaulted fields or new functions, and add a scan option for it in the launcher (the way `--scan weights` exists).
7. Run simulations with it on both datasets (MNIST alone, FashionMNIST alone, plus the 20-class mixed protocol), against the unrolled gate (`T=5`, weight 1), the FCNN controls and the CNN control, all at the Step 1 size.
